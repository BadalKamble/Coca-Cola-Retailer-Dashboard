📌 Project Title
Coca-Cola USA Retailer Sales & Performance Dashboard

📝 Short Description
An interactive Business Intelligence dashboard built to analyze Coca-Cola's USA retailer sales performance across 2022 and 2023. Covers brand-wise revenue, retailer-level comparisons, quarterly profit trends, and unit volume — enabling data-driven decision-making for sales and operations teams.

🎯 Purpose
This project was built to:

Track year-over-year sales growth across 6 beverage brands (Coca-Cola, Dasani, Diet Coke, Fanta, Powerade, Sprite)
Analyze retailer performance across Amazon, BevCo, FizzyCo, Target, Walmart, West Soda
Monitor operating profit margins quarterly
Practice Business Analyst skills — data modeling, KPI design, and dashboard storytelling

ToolUsageMicrosoft Power BIDashboard design, interactive visuals, DAX measuresMicrosoft ExcelData cleaning, source data preparationDAX (Data Analysis Expressions)Custom KPI calculations, variance formulasPower QueryData transformation and loading
